# Wine MLOps Pipeline

A reproducible MLOps pipeline for multi-class wine cultivar classification using scikit-learn and MLflow. This project is the FAST-NUCES MLOps assignment.


## Dataset

The project uses the sklearn Wine dataset:

- 178 samples
- 13 features
- 3 target classes

## Project Goals

- Reproducible data processing
- Tree-based classifier training
- MLflow experiment tracking
- Model Registry
- Automated testing
- GitHub Actions CI
- Model quality gates
## Results
- The result is showing accuracy is 100 because dataset is too small covering only 13 features
