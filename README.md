# Wine MLOps Pipeline

A reproducible MLOps pipeline for multi-class wine cultivar classification
using scikit-learn and MLflow.

## Dataset

The project uses the sklearn Wine dataset:

- 178 samples
- 13 features
- 3 target classes

## Project Goals

- Reproducible data processing
- Tree-based classifier training
- MLflow experiment tracking
- Model Registry
- Automated testing
- GitHub Actions CI
- Model quality gates
